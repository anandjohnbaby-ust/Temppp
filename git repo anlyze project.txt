Below is the complete project, delivered in this message as you asked. It’s called Repo Assistant: paste a public GitHub URL, and it loads the file tree, analyzes the architecture, explains any file, and has an AI agent you can chat with (“where is authentication handled?”).

I chose Groq as the AI provider. Its free tier needs no credit card, and usage is capped by rate limits (requests and tokens per minute or per day). Limits apply per organization and per model, and you can check your current limits at console.groq.com/settings/limits. Groq and OpenRouter both use the OpenAI API format, so switching between them is just a config change (covered at the end).

Part 1: Requirements

Functional requirements

Load a repository: accept a GitHub URL (https://github.com/owner/repo or owner/repo) and show its metadata and file list.
Find files: instant search box that filters files by name or path.
Explain a file: click any file to get an AI explanation (purpose, key parts, how it fits, dependencies).
Analyze architecture: the AI reads the file tree plus key files (README, .csproj, package.json, Dockerfile, etc.) and explains the tech stack, pattern, folder structure and data flow.
Agentic chat: an AI agent with tools (search_files, list_directory, read_file) that decides by itself which files to look at to answer your question.

Non-functional requirements

Layered design: Clean Architecture backend (Domain → Application → Infrastructure → API).
Configuration and secrets: settings via the Options pattern, and API keys stored in dotnet user-secrets, never in code.
Error handling: global errors returned as standard ProblemDetails JSON.
Caching: GitHub responses are cached in memory to avoid rate limits.
Frontend: Angular standalone components, signals-based state, OnPush change detection, and an HTTP error interceptor.

What you need to install

.NET SDK: .NET 10 SDK (or .NET 8 or later). Check with dotnet --version.
Node.js: Node.js LTS (20 or later). Check with node -v.
Angular CLI: install with npm install -g @angular/cli.
Editor: VS Code or Visual Studio.

Free accounts and keys

Groq API key (required): sign up at console.groq.com, then go to API Keys and create a key (starts with gsk_).
GitHub token (optional but recommended): without it, GitHub allows only 60 requests per hour. Create one at GitHub → Settings → Developer settings → Personal access tokens → Fine-grained token, with read-only access to public repositories.

using System.Text.RegularExpressions;
using RepoAssistant.Domain.Exceptions;

namespace RepoAssistant.Domain.Entities;

/// <summary>Identifies a GitHub repository (owner + name).</summary>
public sealed partial record RepositoryReference(string Owner, string Name)
{
    public static RepositoryReference Parse(string? input)
    {
        if (string.IsNullOrWhiteSpace(input))
        {
            throw new InvalidInputException("Repository URL is required.");
        }

        var match = GitHubUrlRegex().Match(input.Trim());
        if (!match.Success)
        {
            throw new InvalidInputException(
                "Enter a valid GitHub repository, e.g. https://github.com/owner/repo or owner/repo.");
        }

        return new RepositoryReference(match.Groups["owner"].Value, match.Groups["repo"].Value);
    }

    public override string ToString() => $"{Owner}/{Name}";

    [GeneratedRegex(@"^(?:https?://)?(?:www\.)?(?:github\.com/)?(?<owner>[A-Za-z0-9-]+)/(?<repo>[A-Za-z0-9._-]+?)(?:\.git)?/?(?:[/?#].*)?$")]
    private static partial Regex GitHubUrlRegex();
}

src/RepoAssistant.Application/Common/RepositoryFileFilters.cs

csharp
namespace RepoAssistant.Application.Common;

public static class RepositoryFileFilters
{
    private static readonly HashSet<string> IgnoredFolders = new(StringComparer.OrdinalIgnoreCase)
    {
        "node_modules", "bin", "obj", ".git", "dist", "build", "out", ".vs", ".idea",
        "vendor", "__pycache__", ".next", "coverage", "packages", ".angular"
    };

    private static readonly HashSet<string> BinaryExtensions = new(StringComparer.OrdinalIgnoreCase)
    {
        ".png", ".jpg", ".jpeg", ".gif", ".ico", ".webp", ".bmp", ".pdf", ".zip", ".gz", ".tar",
        ".exe", ".dll", ".so", ".dylib", ".jar", ".class", ".pyc", ".pdb", ".woff", ".woff2",
        ".ttf", ".eot", ".otf", ".mp3", ".mp4", ".mov", ".avi", ".bin", ".snk", ".db", ".sqlite"
    };

    private static readonly HashSet<string> KeyFileNames = new(StringComparer.OrdinalIgnoreCase)
    {
        "README.md", "package.json", "angular.json", "pom.xml", "build.gradle", "requirements.txt",
        "pyproject.toml", "go.mod", "Cargo.toml", "Dockerfile", "docker-compose.yml",
        "docker-compose.yaml", "Program.cs", "Startup.cs", "main.py", "app.py", "main.ts", "Makefile"
    };

    private static readonly HashSet<string> KeyFileExtensions = new(StringComparer.OrdinalIgnoreCase)
    {
        ".sln", ".slnx", ".csproj"
    };

    public static bool IsIgnored(string path) =>
        path.Split('/').Any(IgnoredFolders.Contains);

    public static bool IsBinary(string path) =>
        BinaryExtensions.Contains(Path.GetExtension(path));

    public static bool IsKeyFile(string path) =>
        KeyFileNames.Contains(Path.GetFileName(path)) || KeyFileExtensions.Contains(Path.GetExtension(path));

    public static bool IsReadme(string path) =>
        Path.GetFileName(path).Equals("README.md", StringComparison.OrdinalIgnoreCase);

    public static int Depth(string path) => path.Count(c => c == '/');
}

src/RepoAssistant.Application/Services/RepositoryAnalysisService.cs

csharp
using System.Text;
using Microsoft.Extensions.Logging;
using Microsoft.Extensions.Options;
using RepoAssistant.Application.Abstractions;
using RepoAssistant.Application.Common;
using RepoAssistant.Application.Dtos;
using RepoAssistant.Application.Models;
using RepoAssistant.Application.Prompts;
using RepoAssistant.Domain.Entities;
using RepoAssistant.Domain.Exceptions;

namespace RepoAssistant.Application.Services;

public sealed class RepositoryAnalysisService(
    IGitHubClient gitHub,
    ILanguageModel languageModel,
    IRepositoryAgent agent,
    IOptions<AnalysisOptions> options,
    ILogger<RepositoryAnalysisService> logger) : IRepositoryAnalysisService
{
    private readonly AnalysisOptions _options = options.Value;

    public async Task<RepositoryOverviewDto> GetOverviewAsync(string repoUrl, CancellationToken ct = default)
    {
        var snapshot = await LoadSnapshotAsync(repoUrl, ct);
        var languages = await gitHub.GetLanguagesAsync(snapshot.Reference, ct);
        var metadata = snapshot.Metadata;

        return new RepositoryOverviewDto(
            metadata.Owner,
            metadata.Name,
            metadata.Description,
            metadata.DefaultBranch,
            metadata.PrimaryLanguage,
            metadata.Stars,
            metadata.HtmlUrl,
            languages,
            snapshot.Files.Select(f => new RepositoryFileDto(f.Path, f.Size)).ToList());
    }

    public async Task<AnalysisResultDto> AnalyzeArchitectureAsync(string repoUrl, CancellationToken ct = default)
    {
        var snapshot = await LoadSnapshotAsync(repoUrl, ct);
        var languages = await gitHub.GetLanguagesAsync(snapshot.Reference, ct);
        var keyFiles = await ReadKeyFilesAsync(snapshot, ct);

        var prompt = new StringBuilder()
            .AppendLine($"Repository: {snapshot.Reference}")
            .AppendLine($"Description: {snapshot.Metadata.Description ?? "n/a"}")
            .AppendLine($"Languages (bytes of code): {string.Join(", ", languages.Select(l => $"{l.Key}={l.Value}"))}")
            .AppendLine()
            .AppendLine("## File tree");

        // Prefer shallow paths so large repos still show their top-level structure.
        var treeEntries = snapshot.Files
            .Select(f => f.Path)
            .OrderBy(RepositoryFileFilters.Depth)
            .ThenBy(p => p, StringComparer.Ordinal)
            .Take(_options.MaxTreeEntries)
            .Order(StringComparer.Ordinal);

        foreach (var path in treeEntries)
        {
            prompt.AppendLine(path);
        }

        if (snapshot.Files.Count > _options.MaxTreeEntries)
        {
            prompt.AppendLine($"... ({snapshot.Files.Count - _options.MaxTreeEntries} more files not shown)");
        }

        prompt.AppendLine().AppendLine("## Key files");
        foreach (var file in keyFiles)
        {
            prompt.AppendLine($"### {file.Path}").AppendLine("```").AppendLine(file.Content).AppendLine("```");
        }

        logger.LogInformation(
            "Analyzing architecture of {Repository} ({FileCount} files, {KeyFileCount} key files)",
            snapshot.Reference, snapshot.Files.Count, keyFiles.Count);

        var markdown = await languageModel.CompleteAsync(PromptTemplates.ArchitectureSystemPrompt, prompt.ToString(), ct);
        return new AnalysisResultDto(markdown);
    }

    public async Task<AnalysisResultDto> ExplainFileAsync(string repoUrl, string filePath, CancellationToken ct = default)
    {
        var path = NormalizePath(filePath);
        if (RepositoryFileFilters.IsBinary(path))
        {
            throw new InvalidInputException($"'{path}' is a binary file and cannot be explained.");
        }

        var snapshot = await LoadSnapshotAsync(repoUrl, ct);
        if (!snapshot.Files.Any(f => f.Path == path))
        {
            throw new NotFoundException($"File '{path}' was not found in {snapshot.Reference}.");
        }

        var content = await gitHub.GetFileContentAsync(snapshot.Reference, snapshot.Metadata.DefaultBranch, path, ct);

        var prompt = new StringBuilder()
            .AppendLine($"Repository: {snapshot.Reference}")
            .AppendLine($"File: {path}");

        if (content.Length > _options.MaxFileChars)
        {
            prompt.AppendLine($"Note: the file is long; only the first {_options.MaxFileChars} characters are shown.");
        }

        prompt.AppendLine().AppendLine("```").AppendLine(Truncate(content, _options.MaxFileChars)).AppendLine("```");

        logger.LogInformation("Explaining {Path} in {Repository}", path, snapshot.Reference);
        var markdown = await languageModel.CompleteAsync(PromptTemplates.FileExplanationSystemPrompt, prompt.ToString(), ct);
        return new AnalysisResultDto(markdown);
    }

    public async Task<ChatResponseDto> ChatAsync(string repoUrl, IReadOnlyList<ChatMessageDto> messages, CancellationToken ct = default)
    {
        if (messages.Count == 0 || messages[^1].Role != ChatRoles.User)
        {
            throw new InvalidInputException("The last message must be from the user.");
        }

        var snapshot = await LoadSnapshotAsync(repoUrl, ct);
        var context = new RepositoryContext(snapshot.Reference, snapshot.Metadata.DefaultBranch, snapshot.Files);
        var recentMessages = messages.TakeLast(_options.MaxChatHistory).ToList();

        var reply = await agent.ChatAsync(context, recentMessages, ct);
        return new ChatResponseDto(reply);
    }

    private async Task<RepositorySnapshot> LoadSnapshotAsync(string repoUrl, CancellationToken ct)
    {
        var reference = RepositoryReference.Parse(repoUrl);
        var metadata = await gitHub.GetMetadataAsync(reference, ct);
        var files = (await gitHub.GetFileTreeAsync(reference, metadata.DefaultBranch, ct))
            .Where(f => !RepositoryFileFilters.IsIgnored(f.Path))
            .ToList();

        return new RepositorySnapshot(reference, metadata, files);
    }

    private async Task<IReadOnlyList<KeyFile>> ReadKeyFilesAsync(RepositorySnapshot snapshot, CancellationToken ct)
    {
        var candidates = snapshot.Files
            .Where(f => RepositoryFileFilters.IsKeyFile(f.Path))
            .OrderBy(f => RepositoryFileFilters.Depth(f.Path))
            .ThenByDescending(f => RepositoryFileFilters.IsReadme(f.Path))
            .ThenBy(f => f.Path, StringComparer.OrdinalIgnoreCase)
            .Take(_options.MaxKeyFiles);

        var results = await Task.WhenAll(candidates.Select(ReadAsync));
        return results.OfType<KeyFile>().ToList();

        async Task<KeyFile?> ReadAsync(RepositoryFile file)
        {
            try
            {
                var content = await gitHub.GetFileContentAsync(snapshot.Reference, snapshot.Metadata.DefaultBranch, file.Path, ct);
                return new KeyFile(file.Path, Truncate(content, _options.MaxCharsPerKeyFile));
            }
            catch (DomainException ex)
            {
                logger.LogWarning("Skipping key file {Path}: {Message}", file.Path, ex.Message);
                return null;
            }
        }
    }

    private static string NormalizePath(string path) =>
        path.Trim().Replace('\\', '/').TrimStart('/');

    private static string Truncate(string value, int maxLength) =>
        value.Length <= maxLength ? value : value[..maxLength] + "\n... [truncated]";

    private sealed record RepositorySnapshot(
        RepositoryReference Reference,
        RepositoryMetadata Metadata,
        IReadOnlyList<RepositoryFile> Files);

    private sealed record KeyFile(string Path, string Content);
}

csharp
using System.Net;
using System.Net.Http.Json;
using System.Text.Json;
using Microsoft.Extensions.Caching.Memory;
using Microsoft.Extensions.Logging;
using Microsoft.Extensions.Options;
using RepoAssistant.Application.Abstractions;
using RepoAssistant.Domain.Entities;
using RepoAssistant.Domain.Exceptions;

namespace RepoAssistant.Infrastructure.GitHub;

internal sealed class GitHubClient(
    HttpClient httpClient,
    IMemoryCache cache,
    IOptions<GitHubOptions> options,
    ILogger<GitHubClient> logger) : IGitHubClient
{
    private static readonly JsonSerializerOptions JsonOptions = new(JsonSerializerDefaults.Web)
    {
        PropertyNamingPolicy = JsonNamingPolicy.SnakeCaseLower
    };

    private readonly TimeSpan _cacheDuration = TimeSpan.FromMinutes(options.Value.CacheMinutes);

    public Task<RepositoryMetadata> GetMetadataAsync(RepositoryReference repository, CancellationToken ct = default) =>
        GetOrCreateCachedAsync(CacheKey(repository, "metadata"), async () =>
        {
            var response = await GetJsonAsync<GitHubRepositoryResponse>(
                $"repos/{repository.Owner}/{repository.Name}", ct);

            return new RepositoryMetadata(
                response.Owner.Login,
                response.Name,
                response.Description,
                response.DefaultBranch,
                response.Language,
                response.StargazersCount,
                response.HtmlUrl);
        });

    public Task<IReadOnlyList<RepositoryFile>> GetFileTreeAsync(RepositoryReference repository, string branch, CancellationToken ct = default) =>
        GetOrCreateCachedAsync(CacheKey(repository, $"tree:{branch}"), async () =>
        {
            var response = await GetJsonAsync<GitHubTreeResponse>(
                $"repos/{repository.Owner}/{repository.Name}/git/trees/{Uri.EscapeDataString(branch)}?recursive=1", ct);

            if (response.Truncated)
            {
                logger.LogWarning("GitHub truncated the file tree for {Repository} (very large repository)", repository);
            }

            IReadOnlyList<RepositoryFile> files = response.Tree
                .Where(item => item.Type == "blob")
                .Select(item => new RepositoryFile(item.Path, item.Size ?? 0))
                .ToList();

            return files;
        });

    public Task<IReadOnlyDictionary<string, long>> GetLanguagesAsync(RepositoryReference repository, CancellationToken ct = default) =>
        GetOrCreateCachedAsync(CacheKey(repository, "languages"), async () =>
        {
            IReadOnlyDictionary<string, long> languages = await GetJsonAsync<Dictionary<string, long>>(
                $"repos/{repository.Owner}/{repository.Name}/languages", ct);

            return languages;
        });

    public Task<string> GetFileContentAsync(RepositoryReference repository, string branch, string path, CancellationToken ct = default) =>
        GetOrCreateCachedAsync(CacheKey(repository, $"content:{branch}:{path}"), async () =>
        {
            var encodedPath = string.Join('/', path.Split('/').Select(Uri.EscapeDataString));
            using var request = new HttpRequestMessage(
                HttpMethod.Get,
                $"repos/{repository.Owner}/{repository.Name}/contents/{encodedPath}?ref={Uri.EscapeDataString(branch)}");

            // Ask GitHub for the raw file instead of base64 JSON.
            request.Headers.Accept.ParseAdd("application/vnd.github.raw+json");

            using var response = await SendAsync(request, ct);
            return await response.Content.ReadAsStringAsync(ct);
        });

    private async Task<T> GetOrCreateCachedAsync<T>(string key, Func<Task<T>> factory)
    {
        if (cache.TryGetValue(key, out T? cached) && cached is not null)
        {
            return cached;
        }

        var value = await factory();
        cache.Set(key, value, _cacheDuration);
        return value;
    }

    private async Task<T> GetJsonAsync<T>(string url, CancellationToken ct)
    {
        using var request = new HttpRequestMessage(HttpMethod.Get, url);
        using var response = await SendAsync(request, ct);

        return await response.Content.ReadFromJsonAsync<T>(JsonOptions, ct)
               ?? throw new ExternalServiceException("GitHub returned an empty response.");
    }

    private async Task<HttpResponseMessage> SendAsync(HttpRequestMessage request, CancellationToken ct)
    {
        HttpResponseMessage response;
        try
        {
            response = await httpClient.SendAsync(request, ct);
        }
        catch (HttpRequestException ex)
        {
            logger.LogError(ex, "Could not reach GitHub");
            throw new ExternalServiceException("Could not reach GitHub. Check your internet connection.");
        }

        if (response.IsSuccessStatusCode)
        {
            return response;
        }

        var status = response.StatusCode;
        var isRateLimited = status == HttpStatusCode.TooManyRequests ||
            (status == HttpStatusCode.Forbidden &&
             response.Headers.TryGetValues("x-ratelimit-remaining", out var remaining) &&
             remaining.FirstOrDefault() == "0");

        response.Dispose();

        throw status switch
        {
            _ when isRateLimited => new RateLimitExceededException(
                "GitHub API rate limit reached. Add a GitHub token (GitHub:Token) or try again later."),
            HttpStatusCode.NotFound => new NotFoundException(
                "Repository or file not found. Check the URL and make sure the repository is public."),
            HttpStatusCode.Unauthorized => new ExternalServiceException(
                "GitHub rejected the token. Check GitHub:Token in your user secrets."),
            _ => new ExternalServiceException($"GitHub API returned status {(int)status}.")
        };
    }

    private static string CacheKey(RepositoryReference repository, string suffix) =>
        $"github:{repository.ToString().ToLowerInvariant()}:{suffix}";
}

using System.Net;

namespace RepoAssistant.Infrastructure.AI;

/// <summary>Turns raw LLM provider errors into friendly domain exceptions.</summary>
internal static class LlmErrorMapper
{
    public static async Task<T> ExecuteAsync<T>(Func<Task<T>> action)
    {
        try
        {
            return await action();
        }
        catch (HttpOperationException ex) when (ex.StatusCode == HttpStatusCode.TooManyRequests)
        {
            throw new RateLimitExceededException(
                "The AI provider's free-tier rate limit was reached. Wait a minute and try again.");
        }
        catch (HttpOperationException ex) when (ex.StatusCode == HttpStatusCode.RequestEntityTooLarge)
        {
            throw new ExternalServiceException(
                "The request was too large for the free tier. Lower the limits in the 'Analysis' settings.");
        }
        catch (HttpOperationException ex) when (ex.StatusCode == HttpStatusCode.Unauthorized)
        {
            throw new ExternalServiceException("The AI provider rejected the API key. Check Llm:ApiKey.");
        }
        catch (HttpOperationException ex)
        {
            throw new ExternalServiceException($"AI provider error: {ex.Message}");
        }
    }
}

src/RepoAssistant.Infrastructure/AI/Plugins/RepositoryPlugin.cs

csharp
using System.ComponentModel;
using Microsoft.Extensions.Logging;
using Microsoft.SemanticKernel;
using RepoAssistant.Application.Abstractions;
using RepoAssistant.Application.Common;
using RepoAssistant.Application.Models;
using RepoAssistant.Domain.Exceptions;

namespace RepoAssistant.Infrastructure.AI.Plugins;

/// <summary>Tools the AI agent can call on its own to explore a repository.</summary>
internal sealed class RepositoryPlugin(RepositoryContext context, IGitHubClient gitHub, ILogger logger)
{
    private const int MaxSearchResults = 50;
    private const int MaxDirectoryEntries = 100;
    private const int MaxFileChars = 8000;

    [KernelFunction("search_files")]
    [Description("Searches the repository for files whose path contains a keyword (case-insensitive). Use it to locate files by name, folder or extension.")]
    public string SearchFiles(
        [Description("Keyword such as 'auth', 'controller', '.csproj' or 'src/services'")] string keyword)
    {
        logger.LogInformation("Agent tool search_files({Keyword})", keyword);

        var matches = context.Files
            .Where(f => f.Path.Contains(keyword, StringComparison.OrdinalIgnoreCase))
            .Take(MaxSearchResults)
            .Select(f => f.Path)
            .ToList();

        return matches.Count == 0
            ? $"No files found matching '{keyword}'."
            : string.Join('\n', matches);
    }

    [KernelFunction("list_directory")]
    [Description("Lists the files and sub-folders directly inside a folder. Use an empty string for the repository root.")]
    public string ListDirectory(
        [Description("Folder path such as 'src', or '' for the root")] string folderPath)
    {
        logger.LogInformation("Agent tool list_directory({Folder})", folderPath);

        var prefix = string.IsNullOrWhiteSpace(folderPath) ? string.Empty : folderPath.Trim('/') + "/";

        var entries = context.Files
            .Where(f => f.Path.StartsWith(prefix, StringComparison.OrdinalIgnoreCase))
            .Select(f =>
            {
                var rest = f.Path[prefix.Length..];
                var slash = rest.IndexOf('/');
                return slash < 0 ? rest : rest[..(slash + 1)]; // folders end with '/'
            })
            .Distinct()
            .Order(StringComparer.OrdinalIgnoreCase)
            .Take(MaxDirectoryEntries)
            .ToList();

        return entries.Count == 0
            ? $"Folder '{folderPath}' was not found or is empty."
            : string.Join('\n', entries);
    }

    [KernelFunction("read_file")]
    [Description("Reads the content of a file. Always use an exact path returned by search_files or list_directory.")]
    public async Task<string> ReadFileAsync(
        [Description("Exact file path, e.g. 'src/Program.cs'")] string path,
        CancellationToken ct)
    {
        logger.LogInformation("Agent tool read_file({Path})", path);

        var normalized = path.Trim().TrimStart('/');
        if (!context.Files.Any(f => f.Path == normalized))
        {
            return $"File '{path}' does not exist. Use search_files to find the exact path.";
        }

        if (RepositoryFileFilters.IsBinary(normalized))
        {
            return "This is a binary file and cannot be read.";
        }

        try
        {
            var content = await gitHub.GetFileContentAsync(context.Repository, context.Branch, normalized, ct);
            return content.Length <= MaxFileChars ? content : content[..MaxFileChars] + "\n... [truncated]";
        }
        catch (DomainException ex)
        {
            return $"Could not read the file: {ex.Message}";
        }
    }
}

using Microsoft.Extensions.Logging;
using Microsoft.Extensions.Options;
using Microsoft.SemanticKernel;
using Microsoft.SemanticKernel.ChatCompletion;
using Microsoft.SemanticKernel.Connectors.OpenAI;
using RepoAssistant.Application.Abstractions;
using RepoAssistant.Application.Common;
using RepoAssistant.Application.Dtos;
using RepoAssistant.Application.Models;
using RepoAssistant.Application.Prompts;
using RepoAssistant.Infrastructure.AI.Plugins;

namespace RepoAssistant.Infrastructure.AI;

internal sealed class SemanticKernelRepositoryAgent(
    Kernel kernel,
    IGitHubClient gitHub,
    IOptions<LlmOptions> options,
    ILoggerFactory loggerFactory) : IRepositoryAgent
{
    public async Task<string> ChatAsync(RepositoryContext context, IReadOnlyList<ChatMessageDto> messages, CancellationToken ct = default)
    {
        // Clone so each request gets its own plugin bound to its own repository.
        var agentKernel = kernel.Clone();
        agentKernel.Plugins.AddFromObject(
            new RepositoryPlugin(context, gitHub, loggerFactory.CreateLogger<RepositoryPlugin>()),
            "repository");

        var history = new ChatHistory(PromptTemplates.BuildAgentSystemPrompt(context));
        foreach (var message in messages)
        {
            if (message.Role == ChatRoles.Assistant)
            {
                history.AddAssistantMessage(message.Content);
            }
            else
            {
                history.AddUserMessage(message.Content);
            }
        }

        var settings = new OpenAIPromptExecutionSettings
        {
            // The model decides which tools to call; Semantic Kernel runs them automatically.
            FunctionChoiceBehavior = FunctionChoiceBehavior.Auto(),
            Temperature = options.Value.Temperature,
            MaxTokens = options.Value.MaxTokens
        };

        var chat = agentKernel.GetRequiredService<IChatCompletionService>();
        var result = await LlmErrorMapper.ExecuteAsync(
            () => chat.GetChatMessageContentAsync(history, settings, agentKernel, ct));

        return string.IsNullOrWhiteSpace(result.Content)
            ? "I couldn't produce an answer. Please try rephrasing your question."
            : result.Content;
    }
}

src/RepoAssistant.Api/ExceptionHandling/GlobalExceptionHandler.cs

csharp
using Microsoft.AspNetCore.Diagnostics;
using Microsoft.AspNetCore.Mvc;
using RepoAssistant.Domain.Exceptions;

namespace RepoAssistant.Api.ExceptionHandling;

/// <summary>Converts exceptions into consistent ProblemDetails JSON responses.</summary>
internal sealed class GlobalExceptionHandler(
    ILogger<GlobalExceptionHandler> logger,
    IProblemDetailsService problemDetailsService) : IExceptionHandler
{
    public async ValueTask<bool> TryHandleAsync(HttpContext httpContext, Exception exception, CancellationToken ct)
    {
        var (status, title) = exception switch
        {
            InvalidInputException => (StatusCodes.Status400BadRequest, "Invalid request"),
            NotFoundException => (StatusCodes.Status404NotFound, "Not found"),
            RateLimitExceededException => (StatusCodes.Status429TooManyRequests, "Rate limit exceeded"),
            ExternalServiceException => (StatusCodes.Status502BadGateway, "External service error"),
            OperationCanceledException => (499, "Request cancelled"),
            _ => (StatusCodes.Status500InternalServerError, "Unexpected error")
        };

        if (status == StatusCodes.Status500InternalServerError)
        {
            logger.LogError(exception, "Unhandled exception");
        }
        else
        {
            logger.LogWarning("{Title}: {Message}", title, exception.Message);
        }

        httpContext.Response.StatusCode = status;

        return await problemDetailsService.TryWriteAsync(new ProblemDetailsContext
        {
            HttpContext = httpContext,
            Exception = exception,
            ProblemDetails = new ProblemDetails
            {
                Status = status,
                Title = title,
                Detail = status == StatusCodes.Status500InternalServerError
                    ? "Something went wrong. Please try again."
                    : exception.Message
            }
        });
    }
}

  overview: RepositoryOverview | null;
  loadingOverview: boolean;
  architecture: string | null;
  loadingArchitecture: boolean;
  selectedFile: string | null;
  fileExplanation: string | null;
  loadingExplanation: boolean;
  chatMessages: ChatMessage[];
  chatBusy: boolean;
  activeTab: AssistantTab;
  error: string | null;
}

const initialState: RepositoryState = {
  repoUrl: '',
  overview: null,
  loadingOverview: false,
  architecture: null,
  loadingArchitecture: false,
  selectedFile: null,
  fileExplanation: null,
  loadingExplanation: false,
  chatMessages: [],
  chatBusy: false,
  activeTab: 'architecture',
  error: null,
};

/** Single source of truth for the app, built on Angular signals. */
@Injectable({ providedIn: 'root' })
export class RepositoryStore {
  private readonly api = inject(RepositoryApiService);
  private readonly state = signal<RepositoryState>(initialState);

  readonly overview = computed(() => this.state().overview);
  readonly loadingOverview = computed(() => this.state().loadingOverview);
  readonly architecture = computed(() => this.state().architecture);
  readonly loadingArchitecture = computed(() => this.state().loadingArchitecture);
  readonly selectedFile = computed(() => this.state().selectedFile);
  readonly fileExplanation = computed(() => this.state().fileExplanation);
  readonly loadingExplanation = computed(() => this.state().loadingExplanation);
  readonly chatMessages = computed(() => this.state().chatMessages);
  readonly chatBusy = computed(() => this.state().chatBusy);
  readonly activeTab = computed(() => this.state().activeTab);
  readonly error = computed(() => this.state().error);

  loadRepository(repoUrl: string): void {
    this.state.set({ ...initialState, repoUrl, loadingOverview: true });

    this.api
      .getOverview(repoUrl)
      .pipe(finalize(() => this.patch({ loadingOverview: false })))
      .subscribe({
        next: (overview) => this.patch({ overview }),
        error: (err: Error) => this.patch({ error: err.message }),
      });
  }

  analyzeArchitecture(): void {
    this.patch({ loadingArchitecture: true, error: null });

    this.api
      .analyzeArchitecture(this.state().repoUrl)
      .pipe(finalize(() => this.patch({ loadingArchitecture: false })))
      .subscribe({
        next: (result) => this.patch({ architecture: result.markdown }),
        error: (err: Error) => this.patch({ error: err.message }),
      });
  }

  explainFile(filePath: string): void {
    this.patch({
      selectedFile: filePath,
      fileExplanation: null,
      loadingExplanation: true,
      activeTab: 'file',
      error: null,
    });

    this.api.explainFile(this.state().repoUrl, filePath).subscribe({
      // Ignore late responses if the user already clicked a different file.
      next: (result) => {
        if (this.state().selectedFile === filePath) {
          this.patch({ fileExplanation: result.markdown, loadingExplanation: false });
        }
      },
      error: (err: Error) => {
        if (this.state().selectedFile === filePath) {
          this.patch({ error: err.message, loadingExplanation: false });
        }
      },
    });
  }

  sendChatMessage(text: string): void {
    const messages: ChatMessage[] = [...this.state().chatMessages, { role: 'user', content: text }];
    this.patch({ chatMessages: messages, chatBusy: true });

    const history = messages
      .filter((m) => !m.isError)
      .map(({ role, content }) => ({ role, content }));

    this.api
      .chat(this.state().repoUrl, history)
      .pipe(finalize(() => this.patch({ chatBusy: false })))
      .subscribe({
        next: (response) => this.appendMessage({ role: 'assistant', content: response.reply }),
        error: (err: Error) =>
          this.appendMessage({ role: 'assistant', content: err.message, isError: true }),
      });
  }

  selectTab(tab: AssistantTab): void {
    this.patch({ activeTab: tab });
  }

  clearError(): void {
    this.patch({ error: null });
  }

  private appendMessage(message: ChatMessage): void {
    this.state.update((s) => ({ ...s, chatMessages: [...s.chatMessages, message] }));
  }

  private patch(partial: Partial<RepositoryState>): void {
    this.state.update((s) => ({ ...s, ...partial }));
  }
}

import {
  ChangeDetectionStrategy,
  Component,
  ElementRef,
  effect,
  inject,
  signal,
  viewChild,
} from '@angular/core';
import { RepositoryStore } from '../../core/state/repository.store';
import { MarkdownPipe } from '../../shared/pipes/markdown.pipe';

@Component({
  selector: 'app-chat-panel',
  imports: [MarkdownPipe],
  templateUrl: './chat-panel.component.html',
  changeDetection: ChangeDetectionStrategy.OnPush,
})
export class ChatPanelComponent {
  protected readonly store = inject(RepositoryStore);
  protected readonly draft = signal('');
  protected readonly suggestions = [
    'Where is the entry point of this application?',
    'Find the files that handle authentication',
    'Which files define the API endpoints?',
  ];

  private readonly messagesContainer = viewChild<ElementRef<HTMLElement>>('messages');

  constructor() {
    // Auto-scroll to the newest message.
    effect(() => {
      this.store.chatMessages();
      this.store.chatBusy();
      const element = this.messagesContainer()?.nativeElement;
      if (element) {
        setTimeout(() => (element.scrollTop = element.scrollHeight));
      }
    });
  }

  protected send(text: string = this.draft()): void {
    const message = text.trim();
    if (!message || this.store.chatBusy()) {
      return;
    }
    this.store.sendChatMessage(message);
    this.draft.set('');
  }
}

Troubleshooting and switching providers
“Llm:ApiKey is missing” on startup: run the dotnet user-secrets set command from inside src/RepoAssistant.Api.
429 / rate limit errors: wait a minute. If architecture analysis on big repos fails, lower the numbers in the Analysis section of appsettings.json.
Agent tool calls fail or return odd errors: some models are weaker at tool calling. Try changing Llm:Model to openai/gpt-oss-120b, which Groq also hosts. Check the Groq console’s Models page for the current list, since model names change over time.
Switching to OpenRouter: set Llm:BaseUrl to https://openrouter.ai/api/v1, put your OpenRouter key in Llm:ApiKey, and set Llm:Model to any model ending in :free that supports tool calling. No code changes are needed.
How to explain it in your interview
Agentic design: the chat uses Semantic Kernel plugins with FunctionChoiceBehavior.Auto(). The LLM decides which tools to call (search, list, read) and the kernel executes them in a loop. That’s the core idea of an AI agent.
Clean Architecture: Application depends only on ILanguageModel and IRepositoryAgent, so the AI provider is swappable.
Production thinking: caching, prompt size limits for token budgets, friendly error mapping, secrets kept out of code, and input validation.
Natural next steps: streaming responses (SSE), a RAG version using embeddings for large repos, unit tests with xUnit and Moq for RepositoryAnalysisService, Docker, and OpenTelemetry tracing.
